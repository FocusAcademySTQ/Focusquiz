# Microlliçons i pràctica guiada

## Cobertura implementada

Hi ha microlliçons específiques per significat, equivalència, simplificació i quatre operacions de fraccions; equacions bàsiques i amb parèntesis; canvi percentual; àrea/perímetre; lectura, comparació, tendència i conclusió de dades; conversió d’unitats; estimació de magnitud o resultat; estratègia multietapa; valor posicional, comparació, ordre i representacions decimals.

Cada microlliçó conté objectiu, explicació, representació visual útil, exemple justificat, comprovació breu i exemple guiat. El progrés es desa a `profile.lessons`; completar-la no crea evidència de domini. Una lliçó apareix quan el procediment és nou i no hi ha evidència autònoma, o reapareix davant dificultats repetides.

No s’han declarat com a coberts suma/resta, multiplicació o divisió decimal perquè el banc actual no ofereix exercicis autònoms d’aquests procediments.

## Retorn, reintents i prerequisits

La primera resposta incorrecta genera evidència diagnòstica autònoma i es conserva textualment. El segon intent queda marcat com assistit. Després de revisar una solució es programa una comprovació del mateix procediment amb una variant nova. Els prerequisits només s’exploren amb evidència repetida compatible; superar-los retorna al procediment original i necessitar reforç no rebaixa automàticament l’habilitat superior.

Llegir una lliçó, rebre una pista o completar una comprovació amb ajuda mai no equival a domini autònom.
