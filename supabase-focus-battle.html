Activar Focus Battle

Aquests són tots els canvis nous que cal fer manualment a Supabase. El frontend només utilitza la clau pública anon; mai no necessita una service key.

1. Executar l’SQL

  1. Obre el teu projecte a Supabase → SQL Editor → New query.
  2. Copia tot el bloc següent, enganxa’l i prem Run.
  3. El script crea les tres taules, índexs, RLS, funcions segures i les afegeix a Realtime.

2. Verificacions

  • A Database → Tables han d’aparèixer battle_rooms, battle_players i battle_answers, totes amb RLS activat.
  • A Database → Replication, comprova que aquestes tres taules són a supabase_realtime (el script ho fa automàticament).
  • No desactivis RLS i no copiïs cap service_role key al projecte.
  • Obre Focus Battle en dos navegadors o dispositius, crea una sala al primer i entra amb el codi al segon.

3. Configuració del frontend

Focus Battle reutilitza portal/supabase-config.js, igual que el portal existent. Si canvies de projecte, actualitza només l’URL i l’anon key d’aquell fitxer (o injecta window.SUPABASE_URL i window.SUPABASE_ANON_KEY en desplegament).
